算法导论第 3 章：函数的增长

发表于 2019-03-10 分类于 程序设计 Waline： 本文字数： 1.3k 阅读时长 ≈ 5 分钟

主要内容

本章讲解如何简化算法的渐近分析，介绍了几类渐近记号。最后简单介绍了常用函数的性质。本章的内容在这里描述得非常简略，但为了保持整个系列的完整性，还是贴出来了。

渐近记号

本章介绍了如下渐近记号，它们的严格定义分别如下：

  1. 若f(n)=Θ(g(n))f(n) = \Theta(g(n))，则存在正常量c1c_1、c2c_2和n0n_0，使得对所有n≥n0n \ge n_0，有0≤c1g(n)≤f(n)≤c2g(n)0 \le c_1 g(n) \le f(n) \le c_2 g(n)
  2. 若f(n)=O(g(n))f(n) = O(g(n))，则存在正常量cc和n0n_0，使得对所有n≥n0n \ge n_0，有0≤f(n)≤cg(n)0 \le f(n) \le c g(n)
  3. 若f(n)=Ω(g(n))f(n) = \Omega(g(n))，则存在正常量cc和n0n_0，使得对所有n≥n0n \ge n_0，有0≤cg(n)≤f(n)0 \le c g(n) \le f(n)
  4. 若f(n)=o(g(n))f(n) = o(g(n))，则对任意c>0c>0，存在常量n0>0n_0>0，使得对所有n≥n0n \ge n_0，有0≤f(n)<cg(n)0 \le f(n) < c g(n)
  5. 若f(n)=ω(g(n))f(n) = \omega(g(n))，则对任意c>0c>0，存在常量n0>0n_0>0，使得对所有n≥n0n \ge n_0，有0≤cg(n)<f(n)0 \le c g(n) < f(n)

为了更形象地理解本节介绍的几种渐近记号，可以在两个函数的渐近比较和两个实数的比较之间做一种类比：

  • f(n)=O(g(n))f(n) = O(g(n))类似于a≤ba \le b
  • f(n)=Ω(g(n))f(n) = \Omega(g(n))类似于a≥ba \ge b
  • f(n)=Θ(g(n))f(n) = \Theta(g(n))类似于a=ba = b
  • f(n)=o(g(n))f(n) = o(g(n))类似于a<ba < b
  • f(n)=ω(g(n))f(n) = \omega(g(n))类似于a>ba > b
